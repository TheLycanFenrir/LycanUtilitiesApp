# Transparency — AI Usage

[← Back to README](README.md)

This project is developed with substantial AI assistance. This document discloses
how that work is distributed, so users and contributors know what they are
getting and can weigh the code accordingly.

## Disclosure

| Share | How it was produced | Description |
| --- | --- | --- |
| **85%** | Generated and refined **via AI**, steered by human prompting | Code authored by an AI model then iterated on through iterative human prompts — the bulk of implementation, wiring, refactors and documentation. |
| **10%** | **Human interaction + AI-driven decisions/recommendations** | Choices shaped by a back-and-forth: a human directed or questioned, and the AI recommended/decided — architecture calls, trade-offs, naming, and design reviews. |
| **5%** | **Human only**, no AI in the loop | Refinements made entirely by hand without any AI assistance. |

## What this means

- AI was used as an accelerator, not an authority. The human maintainer directs
  the work, reviews output, and makes the final calls on what ships.
- AI-generated code can be subtly wrong. Treat it like any third-party
  contribution: read it, test it, and verify behavior before relying on it.
- Mistakes that reach the codebase are the maintainer's responsibility, not the
  model's. Reports and corrections are welcome via the issue tracker.
